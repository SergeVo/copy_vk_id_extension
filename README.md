# VK ID

Браузерное расширение: **правый клик по ссылке на профиль ВК → «Скопировать ID»** → числовой ID профиля уходит в буфер обмена.

Работает **без access token, без входа в ВК и без бэкенда**. Никаких данных никуда не отправляет.

![icon](icons/icon128.png)

## Установка

Chrome / Edge / Яндекс Браузер (Manifest V3, десктоп).

1. Скачай проект:
   ```bash
   git clone https://github.com/SergeVo/copy_vk_id_extension.git
   ```
   (или **Code → Download ZIP** и распакуй).
2. Открой страницу расширений:
   - Chrome / Edge: `chrome://extensions`
   - Яндекс Браузер: `browser://extensions`
3. Включи **Режим разработчика**.
4. Нажми **«Загрузить распакованное расширение»** и выбери папку проекта (ту, где лежит `manifest.json`).
5. После правок кода — кнопка **«Обновить»** на карточке расширения.

## Использование

- Правый клик по ссылке вида `vk.com/...` или `vk.ru/...` → пункт **«Скопировать ID»**.
- Значок расширения мигает подсказкой:
  - **✓** — ID в буфере обмена;
  - **?** — не удалось определить ID (профиль удалён/закрыт);
  - **!** — не удалось записать в буфер.

Пункт меню появляется **только на VK-ссылках**, на обычных сайтах меню не засоряется. Попапа нет — расширение состоит из одного пункта меню.

## Как это работает

ВК отдаёт обычному браузеру SPA-оболочку, в которой id профиля рисуется скриптом. Но вместе с оболочкой приходит `window.cur.apiPrefetchCache` — кэш префетча, где уже есть результат `utils.resolveScreenName`:

```json
{"method":"utils.resolveScreenName","request":{"screen_name":"example_user"},
 "response":{"object_id":123456789,"type":"user"}}
```

Расширение запрашивает `https://vk.com/<имя>` анонимно (`credentials: "omit"`, без куки) и достаёт `object_id` из этого кэша. Резервный путь — `<meta property="og:url" content="…/idNNN">`.

Копирование в буфер: в service worker'е Clipboard API недоступен, поэтому запись идёт через offscreen-документ (`chrome.offscreen`, `execCommand("copy")`), а если он недоступен — через инжект в активную вкладку (`chrome.scripting`).

## Разрешения

| Разрешение | Зачем |
|---|---|
| `contextMenus` | пункт «Скопировать ID» в правом клике |
| `offscreen` | запись в буфер обмена |
| `scripting`, `activeTab` | резервная запись в буфер в активной вкладке |
| `host_permissions: vk.com, vk.ru` | получить страницу профиля |

Телеметрии нет, данные никуда не передаются и не сохраняются.
